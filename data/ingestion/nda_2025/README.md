# NDA 2025 (I and II) — Mathematics and GAT

Hand transcription of the English side of the scanned question booklets (set A for all four papers),
built into prod-load JSON by `source/build2025.py`.

- Keys are DP-solved (`key:dp_solved`, `official_opt` null). Items needing a second look are listed under `flags` in each JSON.
- Withheld (inactive, `content_status = WITHHELD`): NDA_II_2025_MATHS_022 (inconsistent printed data), NDA_II_2025_GK_085 (no correct option).
- Outputs: `nda_maths/prod_load/nda_{i,ii}_2025_maths.json`, `nda_gat/prod_load/nda_{i,ii}_2025_gat.json`.
